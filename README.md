# XCOIN - Criptomoeda Universal

## 🚀 Visão Geral

**XCOIN** é uma criptomoeda universal descentralizada, desenvolvida com tecnologia blockchain de última geração.

## 📋 Características

- ✅ Descentralizada e segura
- ✅ Transações rápidas e eficientes
- ✅ Smart Contracts
- ✅ Escalabilidade
- ✅ Consenso Proof of Stake (PoS)
- ✅ Mining distribuído
- ✅ Carteiras digitais seguras

## 🛠️ Tecnologias

- **Linguagem:** JavaScript/TypeScript
- **Runtime:** Node.js
- **Blockchain:** Implementação própria
- **Criptografia:** SHA-256
- **API:** Express.js

## 🔐 Segurança

- Hashing SHA-256 para integridade de blocos
- Proof of Work para validação
- Carteiras com endereços criptografados
- Validação de transações

## 💡 Como Funciona

### Blockchain
Cadeia de blocos imutável onde cada bloco contém:
- Hash do bloco anterior
- Dados das transações
- Timestamp
- Nonce (para Proof of Work)

### Carteira (Wallet)
Cada usuário tem:
- Endereço único (derivado de hash criptográfico)
- Saldo em XCOIN
- Histórico de transações

### Mining
Processo para validar blocos e ganhar recompensas em XCOIN
